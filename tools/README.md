# Supporting tools

verify_inputs.py checks the three input archive hashes before fitting.
check_overlap_and_transition.py imports the primary src/ modules using the current
repository path. It needs the original data and writes the annual sample summary
through the primary output interface; set MEPS_OUTPUT_DIR to a fresh runs/ folder.

historical/revise_text_for_verified_methods.py is an unchanged record of the
original manuscript edit. Its original input documents and /mnt/data paths are
not a current reproduction entry point. Do not run it against current manuscripts.
